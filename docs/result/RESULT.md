Реализован весь функицонал.

### Интересное
- Использование MVVM, Factory Method, Command, Template Method, Dependency Injection.
- Разделение архитектуры на слои.
- Кэширование данных в приложении.
- Использование go_router, provider.
- Используется fvm для управления версиями Flutter.
- Сделана своя цветовая схема.
- Поддерживается Android и IOS.
